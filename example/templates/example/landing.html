Where each class comes from

From django-mvp

Everything daisyUI: btn, card, the base-* and primary colours, and the theme this page is running.

From this package

py-24, py-20, space-y-6, bg-gradient-to-br, from-primary, hover:scale-105 and transition-transform. django-mvp emits none of them.

Switch the data-theme attribute on <html> to any daisyUI theme. The gradient follows it, because it is built from the semantic palette rather than a literal colour.
