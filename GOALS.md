# Goals

These are the standing directions `daisy-cotton-blocks` works toward. Each one is a capability or
quality to steer by, not a task that gets ticked off. Whether any goal has been served well enough
is decided in the roadmap, the feature specs, and review, never by the goal itself.

This file carries no version numbers or release plan; that lives in the roadmap. For what the
package is, what it stays out of, and the principles that settle a close call, read the
*Scope & philosophy* section of the [README](README.md).

Importance is a tag on each goal, not a ranking:

- **Essential** — not worth adopting without it.
- **Expected** — a complete, dependable version is expected to have it.
- **Aspirational** — a genuine want whose absence never makes the package incomplete.

| ID | Goal | Importance | Status | Notes |
|----|------|------------|--------|-------|
| G1 | Enough blocks that a complete public-facing page can be assembled from the package alone, with no hand-written utility markup left over | Essential | | |
| G2 | Blocks take their look from the host project's active theme, never from values baked into this package | Essential | | |
| G3 | Adopting the package changes nothing about a project it is added to, beyond making the blocks available | Essential | | |
| G4 | Every block is browsable and documented well enough to choose and configure it without reading its template | Essential | | |
| G5 | Each block family offers several distinct layouts, so two projects using the package don't ship the same page | Expected | | |
| G6 | Blocks do more than place content: motion and visual effect where a block calls for it, none where it doesn't | Expected | | |

_Written 2026-09-21. Revise as the goals change._
