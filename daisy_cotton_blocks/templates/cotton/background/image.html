Pair it with `invert` on the block, so the copy is set in `neutral-content` over the dimming layer. **A background image is decoration.** The block hides this whole layer from assistive technology, so the picture carries no alternative text and says nothing a screen reader will hear. An image that means something — a chart, a diagram, a photograph the copy refers to — belongs in the `media` slot of `` or ``, where it is an with an `alt`. An layer rather than a CSS `background-image`: an author-supplied URL interpolated into a `style` attribute is a CSS injection surface that HTML escaping does not close, and a project that wants `srcset` or `loading` can pass them straight through here. Because the picture is the project's and its brightness is unknown, `dim` is what makes the copy readable. Treat "does the copy still read over this picture?" as the setting's whole purpose — on every theme, since the dimming layer is the theme's own `neutral`. Roots at `absolute inset-0`, like every background block, so that two written into the same slot land on top of each other rather than one below the other. See for the reasoning. A background belongs in a `background` slot and nowhere else. ============================================================ {% endcomment %}
