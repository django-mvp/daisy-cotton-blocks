An image that means something — a chart, a diagram, a photograph the copy refers to — belongs in the `media` slot of `` or ``, where it is an with an `alt`. An layer rather than a CSS `background-image`: an author-supplied URL interpolated into a `style` attribute is a CSS injection surface that HTML escaping does not close, and a project that wants `srcset` or `loading` can pass them straight through here. Because the picture is the project's and its brightness is unknown, `dim` is what makes the copy readable. Treat "does the copy still read over this picture?" as the setting's whole purpose — on every theme, since the dimming layer is the theme's own `neutral`. Attributes src URL of the image.
