{% comment %} ============================================================ — the default opening block One column, centred, no media. The arrangement to reach for when the words are the product: a documentation site, a launch announcement, a service that has nothing to screenshot yet. Attributes eyebrow short line above the heading (a category, a release name) title heading text; pass markup through the `title` slot instead lead supporting sentence under the heading level heading level, 1-6, default 1 tone base | soft | glow | neutral — the surface treatment size sm | md | lg | screen — how much vertical room the block takes class extra classes on the outer section Slots announcement above the eyebrow (a pill linking to the latest release) actions the button row; write real markup here footnote under the actions (a trust line, a "no card required") Why the actions are a slot and not a pair of label/href attributes: a call to action is where a project needs full control — a form submit, an hx-post, a target, a tracking attribute — and building the link here would put an author-supplied URL inside an href this template is responsible for escaping. The layout is the hard part and the part this block owns. ============================================================ {% endcomment %}
